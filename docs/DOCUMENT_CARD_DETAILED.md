# 📄 Карточка документа - Детальная информация

## 📋 Описание

Карточка документа - ключевой экран системы СЭД "ЭСАСЫ ПИКИР", предоставляющий полную информацию о документе с детализированным отображением всех реквизитов, автора, корреспондента и доступных операций.

---

## 🎯 Основные возможности

### 1. Детальная информация о документе
- 📝 Полное описание документа
- 📋 Регистрационные сведения (номер, дата, тип, категория, версия)
- ⏰ Сроки и приоритет с индикатором просрочки
- 🏷️ Теги для быстрой классификации

### 2. Информация об авторе
- 👤 Аватар и ФИО
- 💼 Должность
- 🏢 Подразделение
- 📧 Email
- 📱 Телефон

### 3. Информация о корреспонденте
- 🏢 Название организации
- 📄 Иконка и визуальное выделение

### 4. Быстрые действия
- 📥 Скачать документ
- 🖨️ Печать
- 🔗 Поделиться
- 📋 Дублировать

### 5. Вкладки информации
- 📄 **Основная информация** - детальные реквизиты
- ✅ **Согласование** - маршрут и статус
- 🕐 **История** - все изменения
- 📎 **Файлы** - вложения
- 💬 **Комментарии** - обсуждения

## 📊 Структура данных

### Левая колонка (2/3 ширины)

#### 1. Описание документа
```typescript
<div className="bg-gradient-to-br from-blue-50 to-purple-50 rounded-xl p-5">
  <h3>Описание документа</h3>
  <p>{doc.description}</p>
</div>
```

**Особенности:**
- Градиентный фон (синий → фиолетовый)
- Иконка документа
- Полное описание с переносами строк

#### 2. Регистрационные сведения
```typescript
<div className="bg-gray-50 rounded-xl p-4">
  <div>Регистрационный номер: {doc.number}</div>
  <div>Дата регистрации: {fmtDateShort(doc.createdAt)}</div>
  <div>Тип документа: {doc.type}</div>
  <div>Категория: {doc.category}</div>
  <div>Версия: v{doc.version}</div>
</div>
```

**Особенности:**
- Серый фон для выделения
- Разделители между полями
- Иконка календаря

#### 3. Сроки и приоритет
```typescript
<div className="bg-gray-50 rounded-xl p-4">
  <div>Приоритет: <span className="badge">{priorityConf.label}</span></div>
  <div>
    Срок исполнения: 
    {isOverdue && <AlertCircle className="text-red-500" />}
    {fmtDateShort(doc.dueDate)}
  </div>
  <div>Последнее изменение: {fmtDate(doc.updatedAt)}</div>
</div>
```

**Особенности:**
- Индикатор просрочки (красная иконка)
- Цветной бейдж приоритета
- Иконка часов

#### 4. Теги
```typescript
<div className="flex flex-wrap gap-2">
  {doc.tags.map(tag => (
    <span className="px-3 py-1.5 bg-purple-50 text-purple-700 rounded-full">
      #{tag}
    </span>
  ))}
</div>
```

**Особенности:**
- Фиолетовая цветовая схема
- Hover эффект
- Кликабельные теги

## 🔧 Использование

### Навигация к карточке

```typescript
// Из списка документов
<Link to={`/documents/${doc.id}`}>
  {doc.number}
</Link>

// Программная навигация
navigate(`/documents/${doc.id}`);
```

### Получение данных

```typescript
const { id } = useParams<{ id: string }>();
const doc = documents.find(d => String(d.id) === String(id));
const author = employees.find(e => String(e.id) === String(doc.authorId));
```

### Проверка просрочки

```typescript
const isOverdue = doc.dueDate && 
                  new Date(doc.dueDate) < new Date() && 
                  doc.status !== 'executed' && 
                  doc.status !== 'signed';
```
