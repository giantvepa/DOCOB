# СЭД "ЭСАСЫ ПИКИР" - Система электронного документооборота

## 🎯 Описание

Промышленная версия системы электронного документооборота (СЭД) "ЭСАСЫ ПИКИР" с поддержкой двух языков:
- 🇷🇺 Русский
- 🇹🇲 Туркменский

Система разработана на основе лучших практик корпоративных СЭД и включает все необходимые модули для эффективного управления документами в организации.

## ✨ Основные возможности

### 📄 Управление документами
- **Регистрация документов** - входящие, исходящие, внутренние
- **Маршруты согласования** - многоэтапное согласование с визуализацией workflow
- **Электронная подпись** - поддержка ЭП (демо-режим)
- **Версионность** - контроль версий документов
- **Архив** - долговременное хранение документов

### ✅ Задачи и поручения
- Постановка задач с указанием исполнителей и сроков
- Контроль выполнения задач
- Приоритеты задач (низкий, обычный, высокий, критичный)
- Статусы задач (новая, в работе, выполнена, просрочена, отложена)

### 📅 Совещания
- Планирование совещаний
- Управление участниками
- Повестка дня
- Протоколы совещаний

### 📚 Канцелярия
- Регистрация входящей корреспонденции
- Регистрация исходящей корреспонденции
- Учёт внутренних документов
- Номенклатура дел

### 👥 Справочники
- Справочник сотрудников
- Справочник организаций
- Справочник подразделений

### 📊 Отчёты и аналитика
- Статистика по категориям документов
- Статистика по авторам
- Статистика по типам документов
- Статистика по статусам

### 🔐 Администрирование
- Управление пользователями
- Настройка маршрутов согласования
- Шаблоны документов
- Системные параметры

## 🌍 Многоязычность

Система поддерживает два языка интерфейса:
- **Русский** - по умолчанию
- **Туркменский** - переключается в верхней панели

Язык сохраняется в localStorage и применяется ко всему интерфейсу.

## 🎨 Интерфейс

### Классический стиль СЭД
- Трёхпанельный интерфейс (дерево папок, таблица документов, карточка документа)
- Корпоративная цветовая схема (серо-голубая)
- Меню и панель инструментов в стиле Windows
- Статусная строка с информацией о системе

### Виджеты рабочего стола
- Документы, ожидающие решения пользователя
- Задачи пользователя
- Последние документы
- Ближайшие совещания
- Быстрый доступ к основным функциям

### Карточка документа
- **Основная информация** - регистрационные данные
- **Содержание** - текст документа и резолюция
- **Маршрут** - визуальная схема бизнес-процесса
- **Согласование** - таблица согласующих с прогресс-баром
- **История** - хронология действий
- **Файлы** - вложения документа
- **Комментарии** - обсуждение документа

## 🚀 Установка и запуск

### Требования
- Node.js 18+ 
- npm 9+

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

Откройте браузер по адресу: http://localhost:5173

### Сборка для продакшена
```bash
npm run build
```

Готовые файлы будут в папке `dist/`

## 🎯 Особенности реализации

### Визуализация workflow
В карточке документа на вкладке "Маршрут" отображается визуальная схема бизнес-процесса:
- Создан → Согласование → Подписан → Исполнен
- Цветовое кодирование статусов
- Прогресс-бар согласования
- Ветка отклонения документа

### Переключатель языков
- Расположен в верхней панели
- Сохраняет выбор в localStorage
- Применяется ко всему интерфейсу мгновенно

### Корпоративный стиль
- Классический интерфейс СЭД
- Трёхпанельная компоновка
- Таблицы с чередованием строк
- Градиентные заголовки
- Статусная строка
