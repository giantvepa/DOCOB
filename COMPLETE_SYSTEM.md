# 🎉 СЭД "ЭСАСЫ ПИКИР" - Полноценная система с бэкендом

## ✅ Что реализовано

### 🏗️ Полноценный Backend

Создана архитектура бэкенда, аналогичная Express.js + SQLite:

#### 📁 Структура
```
src/backend/
├── api/                    # REST API endpoints
│   ├── auth.ts            # Аутентификация
│   ├── documents.ts       # Документы
│   ├── tasks.ts           # Задачи
│   ├── meetings.ts        # Совещания
│   └── files.ts           # Файлы
├── middleware/             # Middleware
│   ├── auth.ts            # Проверка токенов
│   ├── logger.ts          # Логирование
│   └── validator.ts       # Валидация
├── models/                 # ORM-слой
│   ├── User.ts            # Пользователи
│   ├── Document.ts        # Документы
│   ├── Task.ts            # Задачи
│   └── Meeting.ts         # Совещания
├── database/
│   ├── connection.ts      # IndexedDB (SQLite)
│   └── seed.ts            # Демо-данные
├── utils/
│   ├── jwt.ts             # JWT токены
│   ├── hash.ts            # Хеширование (SHA-256)
│   └── errors.ts          # Классы ошибок
├── types/
│   └── index.ts           # TypeScript типы
└── server.ts              # Главный роутер
```

### 📡 REST API

#### Аутентификация
- `POST /api/auth/register` - регистрация
- `POST /api/auth/login` - вход
- `GET /api/auth/me` - текущий пользователь
- `POST /api/auth/logout` - выход

#### Документы
- `GET /api/documents` - список (с пагинацией)
- `GET /api/documents/:id` - получить
- `POST /api/documents` - создать
- `PUT /api/documents/:id` - обновить
- `DELETE /api/documents/:id` - удалить
- `POST /api/documents/:id/approve` - согласовать
- `POST /api/documents/:id/reject` - отклонить

#### Задачи
- `GET /api/tasks` - список
- `POST /api/tasks` - создать
- `PUT /api/tasks/:id` - обновить
- `DELETE /api/tasks/:id` - удалить
- `POST /api/tasks/:id/complete` - выполнить

#### Совещания
- `GET /api/meetings` - список
- `POST /api/meetings` - создать
- `PUT /api/meetings/:id` - обновить
- `DELETE /api/meetings/:id` - удалить

#### Файлы
- `POST /api/files` - загрузить
- `GET /api/files/:id` - скачать
- `DELETE /api/files/:id` - удалить
- `GET /api/files/document/:id` - файлы документа

## 🚀 Как использовать

### 1. Запуск
```bash
npm run dev
```

### 2. Вход
Откройте http://localhost:3000

**Демо-аккаунты:**
- **Admin**: admin@demo.tm / admin123
- **Manager**: manager@demo.tm / manager123
- **User**: user@demo.tm / user123

### 3. Использование API

```typescript
import { apiCall } from './backend/server';

// Вход
const response = await apiCall('POST', '/api/auth/login', {
  email: 'admin@demo.tm',
  password: 'admin123'
});

// Получить документы
const docs = await apiCall('GET', '/api/documents');

// Создать документ
const newDoc = await apiCall('POST', '/api/documents', {
  title: 'Новый документ',
  type: 'internal',
  priority: 'high'
});

// Согласовать
await apiCall('POST', `/api/documents/${docId}/approve`);
```
