# 📂 Где находится база данных?

## 🎯 Краткий ответ

В **браузере** база данных **не существует как отдельный файл** — она хранится в **IndexedDB** (встроенная БД браузера, аналог SQLite).

---

## 📁 Файлы, связанные с базой данных

### 1. Подключение к БД
```
src/backend/database/connection.ts
```
- Создает базу данных `esasy_pikir_db`
- Определяет все таблицы (11 штук)
- Управляет версиями БД

### 2. Начальные данные
```
src/backend/database/seed.ts
```
- Заполняет БД демо-данными при первом запуске
- Создает 3 пользователей (admin, manager, user)
- Создает демо-документы, задачи, совещания

### 3. ORM-слой (модели)
```
src/backend/models/
├── User.ts          ← Работа с таблицей users
├── Document.ts      ← Работа с таблицей documents
├── Task.ts          ← Работа с таблицей tasks
└── Meeting.ts       ← Работа с таблицей meetings
```

## 💾 Где физически хранятся данные?

### В браузере:
```
Chrome/Edge:   C:\Users\<User>\AppData\Local\Google\Chrome\User Data\Default\IndexedDB\
Firefox:       C:\Users\<User>\AppData\Roaming\Mozilla\Firefox\Profiles\<profile>\storage\permanent\
Safari:        ~/Library/Safari/Databases/
```

### Размер БД:
- Обычно **1-10 МБ** для небольших проектов
- Максимум **50-100 МБ** (зависит от браузера)
- Файлы хранятся как бинарные данные (ArrayBuffer)

## 🔄 Управление базой данных

### Экспорт данных
1. Откройте **"База данных"** в меню
2. Нажмите **"Экспорт"**
3. Скачается файл `esasy_pikir_db_backup_2024-01-15.json`

### Очистка таблицы
1. Откройте **"База данных"** в меню
2. Выберите таблицу
3. Нажмите **"Очистить"**
4. Подтвердите действие

### Полный сброс БД
1. Откройте **"База данных"** в меню
2. Нажмите **"Сбросить БД"**
3. Подтвердите действие
4. Страница перезагрузится
5. Создадутся новые демо-данные

### Через код
```typescript
import { initDatabase } from './backend/database/connection';

// Получить все записи из таблицы
const db = await initDatabase();
const tx = db.transaction('users', 'readonly');
const store = tx.objectStore('users');
const request = store.getAll();

request.onsuccess = () => {
  const users = request.result;
  console.log(users);
};
```

## 🎯 Почему IndexedDB, а не файл?

### Преимущества IndexedDB:
✅ **Встроено в браузер** - не нужно устанавливать  
✅ **Работает оффлайн** - данные сохраняются локально  
✅ **Быстрый доступ** - нет сетевых задержек  
✅ **Транзакции** - как в настоящей БД  
✅ **Индексы** - быстрый поиск  
✅ **Большой объем** - до 100 МБ  
✅ **Безопасность** - изолировано от других сайтов  

### Ограничения:
⚠️ Только в браузере  
⚠️ Нет синхронизации между устройствами  
⚠️ При очистке кэша данные удалятся  
⚠️ Нет прямого SQL доступа

## 🚀 Для продакшена

Если нужна **настоящая серверная БД**, используйте:

### PostgreSQL / MySQL
```bash
# Установите PostgreSQL
sudo apt install postgresql

# Создайте базу
createdb esasy_pikir

# Подключитесь
psql esasy_pikir
```

### SQLite (файловая БД)
```bash
# Создайте файл БД
sqlite3 esasy_pikir.db

# Создайте таблицы
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  email TEXT UNIQUE,
  name TEXT,
  ...
);
```

### MongoDB (NoSQL)
```bash
# Установите MongoDB
sudo apt install mongodb

# Подключитесь
mongo esasy_pikir
```
