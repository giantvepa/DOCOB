### 📱 Адаптивность

- **Mobile** (< 640px): Одноколоночная сетка, скрытая навигация
- **Tablet** (640px - 1024px): Двухколоночная сетка
- **Desktop** (> 1024px): Трёхколоночная сетка, полная навигация

### 🎭 Анимации

```css
/* Появление элементов */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}

/* Скольжение */
@keyframes slideIn {
  from { transform: translateX(-10px); opacity: 0; }
  to { transform: translateX(0); opacity: 1; }
}

/* Hover эффекты */
.hover-card:hover {
  transform: translateY(-2px);
  box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.1);
}
```
