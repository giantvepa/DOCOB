# 🎉 СЭД "ЭСАСЫ ПИКИР" - Полная система документооборота

## 📋 О системе

Полноценная система электронного документооборота с современным интерфейсом, Django backend и универсальными компонентами.

## 🎯 Ключевые компоненты

### 1. Универсальная таблица документов (DocumentTable)

**Назначение:** Единый шаблон для всех реестров документов

**Используется в:**
- ✅ Все документы (`/documents`)
- ✅ Канцелярия (`/registry`) - входящие, исходящие, внутренние
- ✅ Черновики (`/drafts`)
- ✅ На согласовании
- ✅ Архив

**Возможности:**
- 🔍 Полнотекстовый поиск
- 📂 Фильтрация по типу, статусу, приоритету
- 🔄 Сортировка по колонкам
- ☑️ Массовые действия
- 📊 Два вида: таблица и карточки
- 🎨 Настраиваемые колонки

**Пример использования:**
```typescript
<DocumentTable
  title="Входящие документы"
  documents={incomingDocs}
  employees={employees}
  columns={{
    showType: false,
    showPriority: true,
  }}
  filters={{
    showTypeFilter: false,
    defaultType: 'incoming',
  }}
/>
```

## 🚀 Запуск системы

### 1. Backend (Django)

```bash
cd backend

# Создать виртуальное окружение
python -m venv venv

# Активировать (Windows)
venv\Scripts\activate

# Активировать (Linux/Mac)
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Создать миграции
python manage.py makemigrations

# Применить миграции
python manage.py migrate

# Создать тестовых пользователей
python manage.py setup_users

# Запустить сервер
python manage.py runserver
```

Backend доступен: **http://localhost:8000**

### 2. Frontend (React)

```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Frontend доступен: **http://localhost:3000**

## 📡 API Endpoints

### Аутентификация
- `POST /api/auth/register/` - Регистрация
- `POST /api/auth/login/` - Вход
- `POST /api/auth/logout/` - Выход
- `GET /api/auth/me/` - Текущий пользователь

### Документы
- `GET /api/documents/` - Список документов
- `POST /api/documents/` - Создать документ
- `GET /api/documents/:id/` - Детали документа
- `PUT /api/documents/:id/` - Обновить документ
- `DELETE /api/documents/:id/` - Удалить документ
- `POST /api/documents/:id/approve/` - Согласовать
- `POST /api/documents/:id/reject/` - Отклонить

### Задачи
- `GET /api/tasks/` - Список задач
- `POST /api/tasks/` - Создать задачу
- `POST /api/tasks/:id/complete/` - Выполнить задачу

### Совещания
- `GET /api/meetings/` - Список совещаний
- `POST /api/meetings/` - Создать совещание
- `POST /api/meetings/:id/start/` - Начать совещание
