# 🧭 Навигация по системе СЭД "ЭСАСЫ ПИКИР"

## 📋 Описание

Постоянное sidebar-меню обеспечивает навигацию между всеми разделами системы. Меню всегда видно пользователю и позволяет быстро переходить между документами, задачами, совещаниями и другими функциональными разделами.

---

## 🎨 Структура меню

### 1️⃣ Логотип и название (верх)

```
┌─────────────────────────┐
│ 📄 СЭД "ЭСАСЫ ПИКИР"    │
│    Система электронного │
│    документооборота     │
└─────────────────────────┘
```

- **Иконка:** Градиент синий → фиолетовый
- **Размер:** 40x40px
- **Тень:** shadow-lg для объёма
- **Название:** Жирный шрифт (font-bold)
- **Подзаголовок:** Мелкий серый текст

---

### 2️⃣ Навигационные разделы

Меню разделено на **3 группы** для лучшей организации:

#### 📌 Группа 1: Основное

| Иконка | Пункт меню | Бейдж | Описание |
|--------|-----------|-------|----------|
| 🏠 | Рабочий стол | - | Главная страница с виджетами |
| 📄 | Документы | 3 | Список всех документов |
| ✅ | Задачи | 5 | Управление задачами |
| 📅 | Совещания | - | Планирование встреч |

**Особенности:**
- Самые часто используемые разделы
- Бейджи показывают количество новых элементов
- Градиентный фон для активного пункта

#### 📌 Группа 2: Управление

| Иконка | Пункт меню | Описание |
|--------|-----------|----------|
| 📚 | Канцелярия | Регистрация документов |
| 👥 | Сотрудники | Справочник сотрудников |

**Особенности:**
- Административные функции
- Управление данными

#### 📌 Группа 3: Аналитика

| Иконка | Пункт меню | Описание |
|--------|-----------|----------|
| 📊 | Отчёты | Статистика и аналитика |

**Особенности:**
- Аналитические инструменты
- Визуализация данных

## 🎯 Состояния пунктов меню

### Активный пункт

```css
background: linear-gradient(to right, #3b82f6, #9333ea);
color: white;
box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1);
```

**Визуальные эффекты:**
- Градиентный фон (синий → фиолетовый)
- Белый текст и иконка
- Тень для объёма
- Бейдж с полупрозрачным фоном

### Неактивный пункт

```css
color: #4b5563; /* gray-600 */
hover: {
  background: #f3f4f6; /* gray-100 */
}
```

**Визуальные эффекты:**
- Серый текст
- Серая иконка
- При hover: светло-серый фон
- Плавная анимация (transition-all)

### Hover эффект

```css
transition: all 0.2s ease;
hover: {
  background: #f3f4f6;
  transform: translateX(2px);
}
```

**Поведение:**
- Плавное изменение фона
- Лёгкое смещение вправо
- Изменение цвета иконки

## 📐 Размеры и отступы

### Ширина sidebar:
- **Desktop:** 256px (w-64)
- **Mobile:** Скрыт, открывается по кнопке

### Высота:
- **Логотип:** 64px (h-16)
- **Профиль:** Автоматическая
- **Навигация:** Занимает оставшееся пространство (flex-1)

### Отступы:
- **Группы:** mb-6 (24px между группами)
- **Пункты:** py-2.5 (10px сверху/снизу)
- **Иконки:** gap-3 (12px между иконкой и текстом)

### Радиусы:
- **Пункты меню:** rounded-lg (8px)
- **Аватар:** rounded-full (50%)
- **Бейджи:** rounded-full (50%)

## 🔄 Анимации

### Появление sidebar (mobile)

```css
transform: translateX(-100%) → translateX(0);
transition: transform 0.3s ease;
```

### Hover на пункте меню

```css
transition: all 0.2s ease;
hover: {
  background: #f3f4f6;
  transform: translateX(2px);
}
```

### Переключение активного пункта

```css
transition: all 0.2s ease;
```

**Эффекты:**
- Плавное изменение фона
- Плавное изменение цвета текста
- Плавное появление тени

## 🎯 Интерактивность

### Клик по пункту меню

1. **Переход на страницу**
   - React Router навигация
   - Мгновенный переход без перезагрузки

2. **Обновление активного состояния**
   - Проверка `location.pathname`
   - Применение стилей активного пункта

3. **Закрытие sidebar (mobile)**
   - Автоматическое закрытие после клика
   - Плавная анимация скрытия

### Клик по аватару

1. **Открытие выпадающего меню**
   - Информация о пользователе
   - Настройки
   - Выход из системы

2. **Закрытие меню**
   - Клик вне меню
   - Клик по пункту меню

### Клик по кнопке выхода

1. **Вызов функции logout()**
   - Очистка токена
   - Сброс состояния
   - Перенаправление на страницу входа
