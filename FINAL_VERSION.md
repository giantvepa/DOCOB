## 📊 Структура базы данных

### Таблица users
```sql
CREATE TABLE users (
  id TEXT PRIMARY KEY,
  email TEXT UNIQUE,
  password TEXT,
  name TEXT,
  position TEXT,
  department TEXT,
  avatar TEXT,
  role TEXT,
  createdAt TEXT
);
```

### Таблица documents
```sql
CREATE TABLE documents (
  id TEXT PRIMARY KEY,
  number TEXT,
  title TEXT,
  description TEXT,
  type TEXT,
  category TEXT,
  status TEXT,
  priority TEXT,
  authorId TEXT,
  createdAt TEXT,
  updatedAt TEXT,
  ...
);
```

### Таблица files
```sql
CREATE TABLE files (
  id TEXT PRIMARY KEY,
  documentId TEXT,
  name TEXT,
  type TEXT,
  size INTEGER,
  data BLOB,  -- Бинарные данные файла!
  createdAt TEXT
);
```

## 🚀 Как использовать

### 1. Запуск
```bash
npm run dev
```

### 2. Вход в систему
Откройте http://localhost:3000

**Демо-аккаунты:**
- **Администратор**: admin@demo.tm / admin123
- **Менеджер**: manager@demo.tm / manager123
- **Пользователь**: user@demo.tm / user123

Или зарегистрируйте нового пользователя!

### 3. Создание документа
1. Нажмите "Создать" на главной или в "Документах"
2. Заполните форму
3. Нажмите "Создать документ"
4. Откройте документ и загрузите файлы!

### 4. Загрузка файлов
1. Откройте карточку документа
2. Перейдите на вкладку "Файлы"
3. Нажмите на область загрузки
4. Выберите файлы
5. Файлы сохранятся в хранилище!

### 5. Скачивание файлов
1. Откройте документ
2. Перейдите на вкладку "Файлы"
3. Нажмите кнопку скачивания
4. Файл загрузится на ваш компьютер!

### 6. Создание задачи
1. Перейдите в "Задачи"
2. Нажмите "Новая задача"
3. Заполните форму
4. Выберите исполнителя
5. Нажмите "Создать задачу"

### 7. Создание совещания
1. Перейдите в "Совещания"
2. Нажмите "Создать"
3. Заполните форму
4. Выберите участников
5. Добавьте повестку
6. Нажмите "Создать совещание"

## 💾 Хранение данных

### Где хранятся данные?
- **Все данные** хранятся в **IndexedDB** браузера
- **Файлы** хранятся как **бинарные данные** в IndexedDB
- **Сессия** пользователя в **localStorage**

### Преимущества:
- ✅ Данные не теряются при перезагрузке
- ✅ Файлы реально сохраняются
- ✅ Работает оффлайн
- ✅ Нет необходимости в сервере

### Ограничения:
- ⚠️ Данные только в вашем браузере
- ⚠️ При очистке кэша данные удалятся
- ⚠️ Нет синхронизации между устройствами
